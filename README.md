# Sol Wiki

취향과 일상을 위키 형식으로 정리한 개인 소개 페이지입니다.

- 공개 페이지: https://choi-solyi.github.io/sol-wiki/
- 상태: GitHub Pages에 게시 중인 정적 페이지
- `index.html`: 본문, 스타일, 목차와 각주 툴팁 동작을 포함한 단일 파일

## 로컬 확인과 검증

`index.html`을 브라우저에서 엽니다. 별도 패키지 설치, 빌드 또는 서버 실행은 필요하지 않습니다. 현재 자동 테스트 스크립트는 없습니다.

내용 수정 후 목차 링크와 각주 툴팁, 키보드 탐색, 좁은 화면의 가독성을 확인합니다. 기존 제목 앵커와 파일 이름을 유지하고, 공개할 내용만 반영합니다.

## 게시 방식

GitHub Pages가 `main` 브랜치의 `/ (root)`를 게시합니다. 해당 브랜치 변경은 Pages 게시 작업을 실행할 수 있습니다. 변경 후 공개 주소에서 본문·목차·각주가 정상적으로 표시되는지 확인합니다.
